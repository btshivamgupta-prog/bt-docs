# Resource Calendar

Resource Calendar answers *who or what is available* during a period. The route is `admin.calendar-resource`; principal UI files are `frontend/src/view/pages/calendar/ResourceCalendar.vue` and `ResourceCalendarMap.vue`.

Use it to plan technician/resource allocation alongside job demand. Ensure that filters, working hours, leave, and timezones are applied server-side and remain aligned with the assignment rules in Visit and Technicians. A visual slot is not an authorization to overbook a resource.
