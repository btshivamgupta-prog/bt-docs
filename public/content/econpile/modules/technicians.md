# Technicians

Technicians are dispatchable internal people. The module route is `admin.engineer`; code uses “engineer” in paths, including `EngineerController.php` and `frontend/src/view/pages/engineer/`.

## Managed information

Profiles include contact and address data, skills/certificates, color, leave, incident information, documents, and credentials. Availability affects calendars, visit teams, attendance, and timesheet reporting.

Do not equate an active user with an available technician. Assignment must account for status, leave, scheduling collision, skills where applicable, and permission to view personal information.
