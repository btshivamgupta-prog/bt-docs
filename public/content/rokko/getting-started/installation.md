# Installation

Follow these steps to install **Project One** in your environment.

## Prerequisites

- Node.js >= 18
- npm or pnpm
- Redis (optional, for caching)

## Install via npm

````bash
npm install -g @your-org/project-one
````

## Install from source

````bash
git clone https://github.com/your-org/project-one
cd project-one
npm install
npm run build
````

## Verify Installation

````bash
project-one --version
````

Expected output:

````
Project One v1.0.0
````
